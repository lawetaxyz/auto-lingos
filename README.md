# 🤖 Auto Lingos

Automatyczny bot dla serwisu **[lingos.pl](https://lingos.pl/)** w formie skryptu Tampermonkey. Bot samoczynnie uczy się poprawnych odpowiedzi, zapisuje je w pamięci przeglądarki i automatycznie rozwiązuje zadania.

---

## ✨ Funkcje

- 🔍 Rozpoznawanie aktualnych pytań
- 🧠 Zapamiętywanie pytań wraz z odpowiedziami
- 💾 Lokalna baza słówek w przeglądarce
- ⚡ Automatyczne wpisywanie znanych odpowiedzi
- ▶️ Automatyczne przechodzenie do kolejnych pytań
- 📊 Panel pokazujący aktualny stan skryptu
- 🔢 Licznik zapisanych słówek

---

## ⚙️ Instalacja

1. Zainstaluj rozszerzenie **Tampermonkey** w swojej przeglądarce:
   - [Chrome Web Store](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
   - [Firefox Add-ons](https://addons.mozilla.org/pl/firefox/addon/tampermonkey/)

2. Kliknij ikonę rozszerzenia i wybierz **Utwórz nowy skrypt** (*Create a new script*).

3. Wklej kod z pliku **[main.js](main.js)**, a następnie zapisz plik (`Ctrl + S`).

4. Otwórz [Lingos.pl](https://lingos.pl/) i uruchom lekcję.

5. Upewnij się, że skrypt **Auto Lingos** jest włączony w panelu Tampermonkey.

Skrypt powinien rozpocząć działanie automatycznie.
